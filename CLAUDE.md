# Resume Site

Public, static, multilingual (EN / 日本語 / 中文) resume site, built with Go
(`html/template`, stdlib only) and deployed to GitHub Pages via GitHub
Actions. This is a **separate, public repo** — do not confuse it with
`~/personal/resumes`, which holds the private source resume documents
(docx/pdf) plus passport/visa/contract scans and must never be made public.

Live at `https://iamthewang.github.io/resume/`.

## Critical facts

- **GitHub account**: this repo lives under **IAmTheWang** (personal account),
  pushed via the `github-personal` SSH alias
  (`git@github-personal:IAmTheWang/resume.git`). The `gh` CLI on this machine
  is authenticated as **wangWelby** (Welby work account) by default — `gh`
  commands against this repo (e.g. `gh api repos/IAmTheWang/resume/...`) work
  for public read-only calls but will 403 on anything requiring admin/write
  rights (workflow dispatch, repo creation). Use plain `git` over SSH for
  write operations.
- **Privacy redaction**: every data file strips phone number and street
  address from the private source docs — only email, LinkedIn, and a city-level
  location are shown. Every page also ships `<meta name="robots"
  content="noindex, nofollow">` (toggle: `NoIndex` in `internal/site/pages.go`)
  so the site is reachable by direct link but not indexed by search engines.
- **GitHub Pages source must be set to "GitHub Actions"** in the repo's
  Settings → Pages (a one-time manual web UI step, not something a workflow
  file can set). If a deploy run fails with a Pages-environment error, check
  this setting first.
- Commit messages: this account's global convention is Japanese-language
  commit messages (see the user's global `CLAUDE.md`) — applies here too even
  though this repo's content is EN/JA/ZH resume text.
- Never commit/push without the user's explicit go-ahead, even though this is
  a low-stakes personal project — same policy as every other repo.
